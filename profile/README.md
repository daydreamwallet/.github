# Daydream

The wallet you've been dreaming about.

Daydream is a pro Solana wallet. It starts with its agent and test mode: a Solana wallet that runs inside the page, for end-to-end tests and local development. It registers through the Wallet Standard, so it shows up in an app's wallet picker next to real wallets, and it asks for approval in a small in-page popup that Playwright and an agent's browser tool can click. No browser extension needed.

It runs on local validators, devnet and testnet only. Never mainnet, never real funds.

Its home will be daydreamwallet.com.

## Repositories

There are no public repositories here yet. For now the test wallet ships only to Aerosol's own products, as a release tarball.

## Security

Report a vulnerability privately from the affected repository's **Security** tab, or through [this form](https://github.com/daydreamwallet/.github/security/advisories/new). Please don't open a public issue.

Daydream is made by [Aerosol](https://www.aerosol.build).
